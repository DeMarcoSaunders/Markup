# Download Free Fonts

To test the font system, download some free fonts and place them in this directory.

## Recommended Free Fonts

### Google Fonts (Open Source)
- **Roboto**: https://fonts.google.com/specimen/Roboto
- **Open Sans**: https://fonts.google.com/specimen/Open+Sans
- **Lato**: https://fonts.google.com/specimen/Lato
- **Montserrat**: https://fonts.google.com/specimen/Montserrat
- **Source Sans Pro**: https://fonts.google.com/specimen/Source+Sans+Pro

### How to Download from Google Fonts

1. Visit the font page (links above)
2. Click "Download family"
3. Extract the ZIP file
4. Copy the `.ttf` files to this `fonts/` directory
5. Restart the application to see the new fonts

### Example Files to Look For

- `Roboto-Regular.ttf`
- `OpenSans-Regular.ttf`
- `Lato-Regular.ttf`
- `Montserrat-Regular.ttf`
- `SourceSansPro-Regular.ttf`

### Other Free Font Sources

- **Font Squirrel**: https://www.fontsquirrel.com/
- **DaFont**: https://www.dafont.com/
- **1001 Fonts**: https://www.1001fonts.com/

## Testing the Font System

1. Add font files to this directory
2. Run the showcase application
3. Go to the "General" tab
4. Use the "Font Family" dropdown to select different fonts
5. See the UI update with your selected font

## Font Licensing

Make sure to check the license of any fonts you download:
- Google Fonts are open source and free for commercial use
- Always verify licensing terms before using fonts in commercial projects
- Some fonts may require attribution or have usage restrictions
